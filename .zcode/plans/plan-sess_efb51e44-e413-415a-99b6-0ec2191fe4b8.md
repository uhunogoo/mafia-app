## 3. Хелпери sessionStorage-ключів
- `src/lib/identity.ts`: додати поруч з існуючим приватним `storageKey()`:
  ```ts
  /** Ключі sessionStorage кімнати: записує CreateGame, читають PageProvider і JoinForm. */
  export function roomTokenKey(roomId: string) { return `room_${roomId}_token`; }
  export function roomHostClaimKey(roomId: string) { return `room_${roomId}_hostClaim`; }
  ```
- `CreateGame.tsx`: два `sessionStorage.setItem(...)` → `roomTokenKey(room.roomId)` / `roomHostClaimKey(room.roomId)`; додати імпорт.
- `PageProvider.tsx`: `sessionStorage.getItem(\`room_${roomId}_token\`)` → `roomTokenKey(roomId)`; розширити існуючий імпорт з `@/lib/identity`.
- `JoinForm.tsx`: `sessionStorage.getItem(\`room_${roomId}_hostClaim\`)` → `roomHostClaimKey(roomId)`; розширити імпорт.
