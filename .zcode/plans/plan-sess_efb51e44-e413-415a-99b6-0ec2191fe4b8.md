# Приведення mafia-app до joy-of-react-tailwind-style

## Підсумок аудиту

Проект **дуже високо відповідає** стилю: folder-per-component + барелі 25/25, провайдери точно за патерном (named context + default provider + throw-guard + useMemo, без wrapper-хуків), усі хуки через `React.useX` без деструктуризації, `'use client'` першим рядком у 20/20 файлах, `cn` = `twMerge(clsx(...))` всюди, де форвардиться className, lookup-об'єкти замість template-літералів, `focus-visible:` всюди, `type="button"/"submit"`, усі інпути з `<Label htmlFor>`, нуль inline `style={{}}`.

Знайдені відхилення:

**A. Системна прогалина — live regions (skill §8).** У базі немає жодного `aria-live` / `role="status"` / `role="alert"`. Динамічні статуси й помилки не оголошуються скрінрідерами: StatusMessage (покриває RoomStatus, RoomGuard, RoomConnectionProvider), помилкові `<p>` у LoginForm (3), SignUpForm (4), ForgotPasswordForm, UpdatePasswordForm, JoinForm, CreateGame; фаза гри в RoomTopBar; «Кімната повна…/Ще N гравців» у RoomSidebar.

**B. Точкові відхилення:**
1. `src/app/(main)/(auth)/error/page.tsx` — `import { Suspense } from 'react'` замість `import React` + `React.Suspense`.
2. 3 layout-файли (`src/app/layout.tsx`, `(main)/layout.tsx`, `room/[roomId]/layout.tsx`) використовують тип `React.ReactNode` без `import React from 'react'`.
3. Інлайн-стрілкові onChange замість `handleX` function declarations: `ForgotPasswordForm.tsx:83`, `UpdatePasswordForm.tsx:64` (JoinForm робить правильно).
4. Порушений порядок імпорт-груп (React → external → internal → components) у 6 файлах: PageProvider, RulesModal, RoomGuard, RoomSidebar, `(main)/page.tsx`, `(auth)/error/page.tsx`.
5. UI-примітиви Button/Input/Label — named-only shadcn-експорт, без `export default` внизу файла.
6. Дрібниці: `<html lang="en">` при українському UI; `loading.tsx` — «Loading...» англійською без `;`; зайвий `'use client'` у RulesModal; `aria-label="Хост"` на голому `<svg>` (Crown) без `role="img"`; подвійні лапки в JS-рядках `src/app/layout.tsx`.

**Прийняті відхилення (не чіпаємо):** route-файли з `export default function Page()` — ідіома App Router; Card/Dialog — named compound-родини (дозволено skill); cva як варіант-lookup; легітимні arbitrary values (`max-w-[1600px]`, `max-h-[85vh]`, centering calc); не-токенові кольори статусів (green/amber) — кандидат на окрему токенізацію; `generateToken()` замість `crypto.randomUUID` — це запрошувальні токени, не item ID; throw-guard перед хуком у RoomConnectionProvider — інваріант-патерн.

## Кроки реалізації

1. **A11y live regions** (головний фікс):
   - `UI/StatusMessage/StatusMessage.tsx` — на зовнішній div: `role="status"` + `aria-live="polite"`.
   - `role="alert"` на помилкових `<p>`: LoginForm, SignUpForm, ForgotPasswordForm, UpdatePasswordForm, JoinForm, CreateGame.
   - `Room/RoomTopBar/RoomTopBar.tsx` — фаза гри в контейнері з `aria-live="polite"`.
   - `Room/RoomSidebar/RoomSidebar.tsx` — статус заповненості кімнати → `role="status"`.
2. **React namespace:** error/page.tsx → `import React from 'react';` + `React.Suspense` (заодно виправляє порядок імпортів); додати `import React from 'react';` у 3 layout-файли.
3. **Хендлери:** `handleEmailChange` у ForgotPasswordForm, `handlePasswordChange` в UpdatePasswordForm — function declarations у стилі JoinForm.
4. **Імпорти:** вирівняти групи в 6 файлах зі списку B.4.
5. **UI-примітиви до skill-стилю:** Button/Input/Label — `function X(...) {...}` + `export default X;` внизу (named `buttonVariants`, типи лишаються inline); барелі `UI/Button`, `UI/Input`, `UI/Label` → `export { default } from './X'`; механічно оновити всі імпорти-споживачі (~15 файлів, `import Button from ...`).
6. **Дрібниці:** `<html lang="uk">`; loading.tsx → `Завантаження…` з `;`; зняти `'use client'` з RulesModal; Crown → `aria-hidden` + `<span className="sr-only">Хост</span>`; одинарні лапки в `src/app/layout.tsx`.
