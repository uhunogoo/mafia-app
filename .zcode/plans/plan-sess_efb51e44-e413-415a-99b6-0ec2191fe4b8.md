# Поліморфна композиція CardTitle/DialogTitle через asChild

Принцип: сімейні обгортки НЕ містять розміру/ваги (Slot конкатенує класи без twMerge — конфлікти неприйнятні); Title володіє типографікою рівня; call-site контролює вигляд через className на Title. Поточний піксельний вигляд зберігається всюди (явні overrides).

## 1. Компоненти

**`UI/Card/Card.tsx` — CardTitle:**
- Імпорт `Slot` з `@radix-ui/react-slot` (уже в залежностях через Button).
- Props: `React.ComponentProps<'div'> & { asChild?: boolean }`.
- `const Comp = asChild ? Slot : 'div'` (дзеркалить Button).
- Baked-класи: `'leading-none tracking-tight'` (прибрано `font-semibold` — у plain-використаннях RoomSidebar/RulesCard вагу й так перекриває `font-medium` через twMerge, вигляд не зміниться; у композиції вагу дає Title).

**`UI/Dialog/Dialog.tsx` — DialogTitle:**
- Явно деструктуризувати `asChild` і прокинути в `DialogPrimitive.Title` (зараз іде крізь delegated неявно).
- Baked-класи: `'leading-none'` (прибрано `text-lg font-semibold` — єдиний call-site переходить на композицію і явно задає їх через Title; усередині діалогу Radix сам підв'язує id → aria-labelledby на елемент Title).

## 2. Call-sites (8 файлів)

Auth-заголовки — це фактичні заголовки сторінок → `as="h1"`; `text-2xl font-semibold` явно, щоб зберегти точний поточний вигляд (600 замість 700 від h1-дефолту):
- `LoginForm`, `SignUpForm`, `UpdatePasswordForm`: `<CardTitle asChild><Title as="h1" className="text-2xl font-semibold">…</Title></CardTitle>`
- `ForgotPasswordForm`: те саме, з умовним текстом всередині Title.
- `sign-up-success/page.tsx`, `(auth)/error/page.tsx`: те саме (`as="h1"`).
- `JoinForm` (картка всередині сторінки кімнати, зараз безрозмірний): `<Title as="h2" className="text-base">` — h2-семантика + поточний 16px.
- `RulesModal`: `<DialogTitle asChild><Title as="h2" className="text-lg">` — Radix-конвенція (h2) + поточний вигляд.

Усі 8 файлів: додати `import Title from '@/components/UI/Title';`.

Без змін: `RoomSidebar`, `RulesCard` (plain `CardTitle`-лейбли), `Dashboard`.

## 3. Верифікація
`npm run lint` + `npm run build`; grep-ом пересвідчитися, що сирі `text-lg`/`text-2xl` не залишились на обгортках.
