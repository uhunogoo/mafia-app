# Аудит усіх компонентів за скілом → виправлення (v2)

## Результат аудиту

### ✅ Відповідають скілу (без змін)
Всі власні компоненти: CreateGame, InviteLink, LogoutButton, SiteHeader, ThemeToggle, PageProvider, RoomConnectionProvider, 5 форм, RoomGuard, PlayerGrid, PlayerSlot, RoomSidebar, RoomTopBar, RulesCard, RulesModal, StatusMessage, barrels, constants.ts. One-liner inline `onChange={(e) => setEmail(...)}` — тривіальні, не порушення.

### ❌ Порушення — кластер `UI/` (вендорені shadcn-примітиви: Button, Card, Dialog, Input, Label)
1. **§3**: `import * as React from "react"` → `import React from 'react'`
2. **§9**: подвійні лапки JS-рядків → одинарні (JSX-атрибути — подвійні)
3. **§4**: `const X = React.forwardRef((...) => ...)` arrow-const → function-декларації; ref — звичайний prop (React 19), forwardRef/displayName зникають; refs ніхто не передає (перевірено)
4. **§4 правило експортів**: збірні `export { ... }` блоки знизу → інлайн `export function/const` (Button: `export const buttonVariants` інлайн)
5. **§4**: `...props` → `...delegated`
6. **§4**: Button — дефолт `type = 'button'` (без нього кнопка у формі неявно submit)
7. **§8**: Dialog close — `focus-visible:outline-none` → `focus-visible:outline-hidden` (Tailwind v4)

Card/Dialog-родини — compound components виняток (структура лишається, стиль членів оновлюється). Барелі не чіпаю.

### 📜 §3 скіла — переписати правило (англійською)
Було: «**Always import it**, even if only used via the `React.useX` namespace».
Стане: import React **коли використовується щось з бібліотеки React** (хуки, `React.useContext`, `React.Suspense`, типи на кшталт `React.ReactNode`) — і завжди через `React.` namespace, без деструктуризації; файли без звернень до React API імпорт не мають.
+ §12 checklist: «`import React from 'react';` present at the top» → «present when the React namespace is used (hooks, context, types) — absent otherwise».

### Наслідок для 5 файлів
LogoutButton, SiteHeader, RoomTopBar, PlayerSlot, RulesModal — **не** додаємо `import React` (React.* там не використовується). Тесту з lint уже не потрібно.
