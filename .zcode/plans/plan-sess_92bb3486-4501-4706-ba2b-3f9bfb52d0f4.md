# PlayerSlot в окремий компонент + рендер через range + прямі React.useContext

## 1. Конвенції (скіл + AGENTS.md)
- Скіл §2: провайдерський файл = провайдер + контекст; споживачі читають контекст напряму `React.useContext(Context)` з явним throw-guard-ом; без хуків-обгорток у провайдері
- Скіл §6: прибрати «consumer hook exported alongside», додати приклад guard-а
- AGENTS.md: оновити рядок Structure відповідно (+ спільні константи — `src/constants.ts`)

## 2. Хелпери
- `src/lib/utils.ts`: додати `range(start, end?, step = 1)` — код користувача, адаптований до TS (для рендерингу фіксованих сіток)
- `src/constants.ts` (новий): `DEFAULT_MAX_PLAYERS = 12` (зараз магічне `12` у PlayerGrid, RoomSidebar, RoomTopBar)

## 3. Провайдери (знімаємо магію)
- `PageProvider.tsx`: видалити `usePageContext` — лишаються `PageContext` (named) + `PageProvider` (default)
- `RoomConnectionProvider.tsx`: `createRoomContext<MafiaStateView>()` (типізує селектори — каст `state as MafiaStateView` зникає; перевірено по типах Colyseus), видалити `useMafiaState` + import `Snapshot`; сам провайдер читає `React.useContext(PageContext)` + guard

## 4. PlayerSlot → окремий компонент
- Нова папка `Room/PlayerSlot/PlayerSlot.tsx` + барель `index.ts`; вміст слота **поки без змін** (аватар з ініціалом + корона хоста + нікнейм), тільки імпорти (Crown, cn, тип RoomPlayerView)

## 5. PlayerGrid — рефактор
- **Прибрати Map/розсадку повністю**: гравців розсаджує сервер (seatIndex), клієнт лише рендерить
- Рендер: `range(capacity).map((seatIndex) => ...)` — на кожне місце `findSeatedPlayer(players, seatIndex, myGuestId)` (маленький хелпер зверху файла: шукає в `Object.entries` за `seatIndex`, повертає `{ player, isYou }`) → `PlayerSlot` або `EmptySlot`
- `EmptySlot` лишається приватним субкомпонентом у PlayerGrid (скіл §2: субкомпонент одного батька живе в тому ж файлі)
- Прямий `React.useContext(PageContext)` + throw-guard; `DEFAULT_MAX_PLAYERS`

## 6. Споживачі
- `RoomSidebar`: прямий контекст + guard, `RoomContext.useRoomState` ×2, `DEFAULT_MAX_PLAYERS`
- `RoomTopBar`: `RoomContext.useRoomState` ×3, `DEFAULT_MAX_PLAYERS` (PageContext не читає)
- `RoomGuard`, `JoinForm`: прямий контекст + guard; у JoinForm усі `useState` до guard-а (rules-of-hooks)
