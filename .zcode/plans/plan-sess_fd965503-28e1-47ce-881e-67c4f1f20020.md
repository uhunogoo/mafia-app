# Блок «Кімната:» для гостей — тільки інформація

Зміни в одному файлі: `src/components/room/room-sidebar.tsx`.

**Спільне (усі гравці):**
- Посилання-запрошення (як зараз).

**Гість (замість вимкнених контролів):**
- «Кількість гравців» як текст: `Гравців: 6 з 12` (без перемикача);
- склад ролей (як зараз, текст);
- пасивний індикатор: `Ще N гравців` / при повній кімнаті — `Кімната повна, хост може розпочати гру`;
- рядок-підказка `Налаштуваннями керує хост`.

**Хост (без змін):**
- перемикач 10/11/12 (активний), склад ролей, кнопки «Перемішати» та «Ще N гравців»/«Почати гру».

Тобто `isHost ? <selector + кнопки> : <текстові еквіваленти>`; кнопки для гостей не рендеряться взагалі (нічого вимкненого немає). Верхня панель лишається без змін.

## Перевірка
`npm run lint` + `npm run build`; у браузері: хост бачить повний блок, гість — спрощений (перевірю на тестовій кімнаті, гостьовий вигляд — через Node-гостей або свіжим профілем).
